## Required follow-through before approval

- Authenticate imported COA semantics, critical source coverage/freshness, electrical and work policies. Explicit SIMULATED access-envelope declarations now allow bounded prototype validation; imported authority remains blocked.
- Effective train-run, COA and freight revisions are now selected before horizon filtering. A row still does not establish complete traffic coverage; source coverage declarations require domain authentication before operational use.
- The M11 first-feasible baseline uses the same generated alternatives and constraint model as CP-SAT for saved comparisons. It remains a finite-candidate baseline, not a guarantee about all possible railway schedules.
- M13 atomically rechecks validation, current operational revision and resource reservations on approval. A historical PASS report alone never constitutes approval.
